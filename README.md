# 熟齡嘉年華 3D 場配＋熟齡大富翁

2026 屏東熟齡社團嘉年華（12/19，屏東縣立體育館旁）的 3D 場地配置圖，可以在場地裡走動、鳥瞰、切換日夜，並內建一套繞行整個活動場地的實境大富翁遊戲。

整個專案只有一個檔案 `index.html`，不需要安裝或建置，用瀏覽器打開就能使用。

## 線上瀏覽（GitHub Pages）

1. 把這個資料夾的檔案上傳到一個 GitHub repository。
2. 到 repository 的 **Settings → Pages**。
3. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等一兩分鐘，頁面上方會出現網址，格式是 `https://<你的帳號>.github.io/<repository 名稱>/`。

## 場地模型

- 入口意象、熟齡社團、政令宣導、市集攤位共 75 攤，舞台與觀眾席、拍照打卡區、服務與醫護站。
- 熟齡挑戰賽 4 個小遊戲。
- 體育館、田徑場與看台、屏東公園等周邊設施。
- 操作方式：
  - 電腦：W A S D 或方向鍵移動，拖曳滑鼠轉視角。
  - 手機：左下搖桿移動，滑動畫面轉視角。
  - 點地面會自動走過去，點兩下地面直接傳送。

## 熟齡大富翁

點左側「熟齡大富翁」到入口起點，按「開始玩」即可開局。1～4 人，每個位置可以選玩家或電腦。

### 路線與土地

- 從入口大門出發，走過四條攤位走道、舞台四周、服務醫護站、挑戰賽區，沿步道到體育館南側草坪與廣場，再回到入口。
- 一圈 128 格，不穿過道路、建築或球場。
- 72 塊土地以屏東景點命名，分成 9 個地區，停下來會出現景點明信片。

### 建築

買地後可以蓋 5 種建築，各 5 級。別人停下來時要轉盤決定付多少，等級越高金額越大：

- **飯店**：轉住幾晚，住宿期間要休息。
- **酒店**：轉每天消費和天數。
- **賣場**：轉消費金額和倍數，二級以上路過也會順便買。
- **風景區**：轉門票倍數。
- **廟宇**：轉香油錢和倍數，捐款的人可能得到神明保佑。

### 其他玩法

- **錢與股票**：銀行存提款；6 檔股票每天漲跌，新聞也會影響股價，每月發股利。
- **交通工具**：車行賣腳踏車、電動機車、小轎車。
- **卡片道具**：便利商店賣 17 種卡片、7 種道具，也有刮刮樂；市集攤位可以買小吃，吃了有不同效果。
- **神明**：9 位神明會跟著你 5 回合，有好有壞。
- **趣味關卡**：機會、命運、新聞、擲筊、屏東問答、搶紅包、舞台表演、拍照打卡、賽跑、熟齡挑戰賽。
- **角色**：四位熟齡角色各有台詞，彼此會互相鬥嘴。
- **聲音**：背景音樂由多種傳統樂器音色演奏，可在選單開關音樂、音效和角色語音。

## 存檔

- 遊戲每回合自動存在瀏覽器（localStorage），同一台裝置、同一個瀏覽器可以接著玩。
- 在 claude.ai 上開啟時，另外會存到 Claude 帳號的雲端資料；放在 GitHub Pages 時只會存在瀏覽器。
